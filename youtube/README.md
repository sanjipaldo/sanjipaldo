# 유튜브 영상 작업 폴더

두고보는 문대표 채널 영상을 HyperFrames로 편집하는 곳이에요. 두고마켓 앱과는 별개이고 배포되지 않습니다.

## 쇼츠 촬영 방법 (레퍼런스 형식)

완성 화면은 세 가지가 번갈아 나와요: 얼굴 전체 / 위 그래픽 + 아래 얼굴 / 그래픽 전체. 자막은 화면 가운데에 두 줄.

- 휴대폰 **세로**, 4K(없으면 1080p) 30fps, 삼각대 고정
- **가슴 위까지**, 정수리가 화면 위에서 약 1/4, 눈높이는 약 1/3
- 화면 가운데에서 좌우로 크게 움직이지 않기 (아래 절반만 잘라 쓰는 장면이 많아요)
- 핀마이크, 에어컨·선풍기 끄기, 얼굴 정면을 밝게
- 녹화 시작 후 3초 조용히 → 말 시작
- 틀리면 멈추지 말고 **2초 쉬고 그 문장 처음부터** 다시 (마지막 버전만 남겨요)
- 45~60초 분량, 말은 조금 빠르게

## 대본 구성 (레퍼런스 순서)

1. 훅 (3초): 시청자 고민을 질문으로 — "○○ 아직도 이렇게 하세요?"
2. 해결 약속: "○○하면 돼요. 방법 바로 알려줄게요"
3. 번호 단계 3~4개: "첫 번째 … 두 번째 …" (단계마다 보여줄 화면 메모)
4. 혜택이나 결과 한 줄
5. 댓글 유도: "댓글에 '○○' 남기면 자료 보내드릴게요"

## 저한테 주실 것

| 파일 | 비고 |
|---|---|
| 세로 얼굴 원본 영상 | 원본 그대로 (카톡 전송 X) |
| 대본 | 실제로 읽은 최종본, 단계마다 보여줄 화면 메모 |
| 보여줄 화면 | 화면 녹화·캡처 (앱, 사이트, 자료) |
| 브랜드 | 로고 PNG, 브랜드 색 (처음 한 번만) |

구글 드라이브 폴더에 올리고 공유를 **"링크가 있는 모든 사용자"**로 바꾼 뒤 링크를 주세요.

## 작업 순서

음성 인식(한국어) → NG·공백 컷 → 장면 구성표 확인 → 샘플 확인 → 완성 MP4
