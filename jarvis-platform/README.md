# JARVIS AI (자비스 AI) — 사업 자동화 플랫폼

사장님 대신 24시간 운영하는 자동화 비서. 자동화 모듈을 하나씩 붙여 나가며, **첫 번째 모듈이 유튜브 채널 운영**입니다.
홈(`/hub`)에서 모듈을 고르고, 새 모듈은 `src/views.js` 의 `MODULES` 목록에 추가합니다.

## 모듈 01 · 유튜브 채널 운영 (`/youtube`)

1. 로그인 → **유튜브 영상 링크 · 제휴사 · 키워드 · 레퍼럴 링크** 입력 → "자동화 시작"
2. 그 영상에 키워드 댓글(예: `후커블`)이 달리면 자비스가 **대댓글**을 답니다 (1회용 인증코드 + 신청 폼 링크)
3. 구독자가 신청 폼에 **이메일**을 넣으면, 그 이메일로 **레퍼럴 링크 메일이 자동 발송**됩니다
4. 영상 링크를 비우면 **내 채널 전체**가 대상이 되고, 새로 올리는 영상도 자동으로 감지해 안내 댓글을 남깁니다

> 같은 규칙을 구글 시트 하나로 쓰는 버전은 [`../youtube-referral-bot`](../youtube-referral-bot) 에 있습니다. 이 폴더는 그것을 여러 사람이 쓰는 웹사이트로 만든 것입니다.

## 바로 실행해 보기

```bash
cd jarvis-platform
npm start                # 또는: node --env-file=.env src/server.js
# → http://localhost:3000  (테스트 계정 admin / admin)
```

외부 패키지 설치가 필요 없습니다 (Node.js 18 이상, 권장 22).

구글 연결 정보가 없으면 **데모 모드**로 동작합니다. `가상 유튜브` 메뉴에서 가상 영상을 올리고 구독자처럼 댓글을 달면, 실제와 똑같이 대댓글 → 신청 폼 → 메일까지 전부 시험할 수 있습니다.

## 실제 유튜브에 연결하기 (플랫폼 운영자가 한 번)

1. [Google Cloud Console](https://console.cloud.google.com/) 에서 프로젝트 만들기
2. **API 및 서비스 → 라이브러리** 에서 `YouTube Data API v3` 사용 설정 (Gmail 발송도 쓰려면 `Gmail API` 도)
3. **OAuth 동의 화면** 설정 → 범위에 `youtube.force-ssl` (+ `gmail.send`) 추가 → 처음에는 "테스트" 상태로 두고 사용할 구글 계정을 **테스트 사용자**로 등록 (최대 100명)
4. **사용자 인증 정보 → OAuth 클라이언트 ID (웹 애플리케이션)** 만들기
   승인된 리디렉션 URI: `https://내도메인/auth/google/callback`
5. `.env` 에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `BASE_URL` 넣고 서버 재시작
6. 각 사용자: **유튜브 채널 운영 → 채널 설정 → 유튜브 채널 연결** → 내 채널 선택 → (처음엔 테스트모드로 확인) → 테스트모드 끄기

> 누구나(100명 넘게) 쓰게 공개하려면 구글의 **앱 검증**을 받아야 합니다. `youtube.force-ssl` 은 민감한 범위라 검증 심사(개인정보처리방침 URL, 시연 영상 등)가 필요하고, `gmail.send` 는 제한된 범위라 보안 평가까지 필요합니다. 공개 운영이라면 메일은 Resend 방식을 권장합니다.

## 메일 발송 방식 (사용자마다 설정)

| 방식 | 설명 |
|---|---|
| 미리보기 (기본) | 실제로 보내지 않고 `보낸 메일` 에만 남김. 시험용 |
| Resend | [resend.com](https://resend.com) 에서 도메인 인증 후 API 키 입력. 공개 서비스에 권장 |
| Gmail | 연결한 구글 계정의 Gmail 로 발송. 일반 계정 하루 100통, Workspace 1,500통 |

## 서버에 올리기

계속 켜져 있어야 10분마다 댓글을 확인할 수 있으므로, 항상 켜진 서버(Render, Railway, Fly.io, 개인 VPS 등)에 올립니다. Vercel 같은 서버리스는 맞지 않습니다.

```bash
docker build -t jarvis .
docker run -d -p 3000:3000 -v jarvis-data:/app/data --env-file .env jarvis
```

데이터는 `data/db.json` 한 파일에 저장됩니다 (구글 토큰·Resend 키는 암호화). 백업은 이 파일만 복사하면 됩니다.

## 지켜지는 규칙

- 레퍼럴 링크는 **댓글에 절대 나가지 않고** 메일로만 전달 (대댓글 문구에 링크를 넣으면 저장이 막힘)
- 인증코드는 1회용 · 남의 코드로 신청하면 "이미 사용된 코드"
- 같은 사람에게는 캠페인별로 한 번만 답글, 같은 이메일에는 한 번만 발송 (끌 수 있음)
- 하루 답글 한도(유튜브 API 무료 할당량 기준 최대 약 190개), 할당량 초과 시 멈췄다가 다음 날 이어서
- 내 채널의 댓글(자비스 안내 댓글 포함)에는 반응하지 않음
- 테스트모드: 실제 유튜브에 답글을 달지 않고 기록만
- 로그인 · 신청 폼 시도 횟수 제한, 모든 폼에 CSRF 보호, 비밀번호 scrypt 해시

## 한계

- 좋아요를 눌렀는지는 유튜브 API가 알려주지 않아 확인할 수 없습니다.
- 댓글 고정(핀)은 API로 할 수 없어 직접 눌러야 합니다.
- 검토 대기로 보류된 댓글은 승인되기 전까지 보이지 않습니다.
