# 두고캠퍼스 — 강사가 운영하는 강의 플랫폼

한 화면(`index.html`) 안에 세 영역이 있습니다.

| 영역 | 주소 | 로그인 | 디자인 |
|---|---|---|---|
| 수강생 센터 | `#/login`, `#/home` … | 강사 선택(기억됨) → 이름 + 전화번호 뒷자리 | Wise (라임 그린) |
| 강사센터 | `#/center` … | 강사 이름 + 전화번호 뒷자리 | Meta (코발트 블루) |
| 마스터 관리자 | `#/center/master` … | 강사센터 로그인 화면의 ‘마스터 관리자’ 탭 · `ADMIN / ADMIN` (대소문자 무관) | Meta |

프레임워크 없는 HTML/CSS/JS 정적 앱이고, 데이터는 브라우저 `localStorage`에 저장됩니다(서버 미연결).

## 실행

```bash
python3 -m http.server 4321 --directory class
# http://localhost:4321
```

배포용 사본은 `dist/class/`에 있습니다. `class/`를 고친 뒤에는 `rm -rf dist/class && cp -r class dist/class`로 맞춰 주세요.

## 운영 규칙

- **기수**: 1주차 시작일만 정하면 `n주차 공개 = 시작일 + 7×(n-1)`, `과제 마감 = 공개 + 6일`로 자동 계산됩니다. 같은 커리큘럼을 기수마다 다시 쓸 수 있습니다.
- **수강생 상태**: 승인 대기 → 수강 중(승인) / 거절, 수강 중 → 탈퇴. 승인된 수강생만 로그인됩니다. 탈퇴·거절은 기록이 남아 복구할 수 있습니다.
- **수강 신청**: 수강생 로그인 화면의 ‘수강 신청하기’ → 강사가 ‘신청 받기’를 켠 기수 중에서 고릅니다.
- **과제**: 제출 즉시 자동검수(사진·링크·글자 수·필수 단어). 강사가 승인/보완 요청하면 그 결과가 최종입니다. 필수 과제를 모두 통과하면 수료증이 열립니다.
- **강의 일정**: ‘강의 오픈’과 ‘과제 마감’은 자동, 라이브 Q&A·공지·챌린지·행사는 강사가 추가합니다. ‘모든 기수 반복(주차·요일)’ 또는 ‘특정 기수 하루’로 정합니다.
- **Q&A**: ‘자주 묻는 질문’은 분류별로 보이고, 강사센터에서 ‘한꺼번에 붙여넣기’(`[분류]` / `Q.` / `A.` 형식)로 한 번에 등록할 수 있습니다. ‘요청사항’은 프로그램 오류·불편 신고 게시판으로, 모두 비공개(작성자·강사만 열람)이며 스크린샷을 3장까지 첨부합니다. 강사가 ‘요청사항 답변’에서 답하면 수강생 상세 화면에 바로 보입니다.
- **콘텐츠**: 수강생 메뉴와 같은 이름으로 강사센터 ‘수강생 화면 콘텐츠’에서 모두 고칠 수 있습니다. 유튜브는 주소를 붙여 넣으면 됩니다.
- **미리보기**: 강사센터 ‘수강생 화면 보기’ → 선택한 기수 기준의 수강생 화면. 미리보기 제출 기록은 실제 수강생과 분리됩니다.
- **플랫폼 분양**: 마스터에서 ‘새 강사 플랫폼’을 만들면 기본 메뉴·예시 커리큘럼·1기가 들어간 상태로 시작합니다. ‘강사센터 접속’으로 대신 관리할 수 있습니다.
