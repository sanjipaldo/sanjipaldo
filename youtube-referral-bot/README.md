# 🤖 나만의 유튜브 채널 AI 자비스

유튜브 댓글 → 자동 대댓글 → 신청 폼 → 레퍼럴 메일, 그리고 **새 영상 업로드까지 자동으로 따라가는** 채널 운영 비서입니다.

내 유튜브 채널에 **"후커블"** 같은 키워드 댓글이 달리면 봇이 알아서

1. 그 댓글에 **대댓글**을 달고 (1회용 인증코드 + 신청 폼 링크 포함)
2. 구독자가 폼에 **이메일**을 넣으면
3. 해당 제휴사의 **비밀 레퍼럴 링크를 메일로 자동 발송**합니다.

서버나 유료 프로그램 없이 **구글 시트 + Apps Script(무료)** 로 돌아갑니다.
한 번 켜두면 시트를 닫아도, 컴퓨터를 꺼도 구글 서버에서 24시간 동작합니다.

```
유튜브 댓글 "후커블 신청!"
      │  (10분마다 확인)
      ▼
봇 대댓글: "@이름님 감사합니다! 👉 신청링크 (인증코드 K7Q2MX)"
      │
      ▼
구독자: 폼에 이메일 입력 (코드는 링크로 자동 입력)
      │  (제출 즉시)
      ▼
봇 메일: "요청하신 후커블 전용 링크입니다 👉 https://...ref=비밀코드"
```

## 무엇을 할 수 있나

| 기능 | 설명 |
|---|---|
| 제휴사(캠페인) 여러 개 | 후커블, A사, B사… 줄마다 키워드·답글·레퍼럴 링크·메일 문구를 따로 |
| 영상별 설정 | 캠페인마다 "전체 영상" 또는 "특정 영상만" 지정 |
| 문구 언제든 변경 | 시트 칸만 고치면 다음 확인부터 바로 적용 (코드 수정 불필요) |
| 답글 여러 버전 | `---` 로 나누면 무작위로 골라 달아서 스팸 판정 예방 |
| 1회용 인증코드 | 댓글 단 사람만 링크를 받도록. 코드 한 번 쓰면 끝 |
| 레퍼럴 링크 비공개 | 링크는 댓글에 절대 안 나가고 메일로만 전달 |
| 중복 방지 | 같은 사람·같은 이메일에는 제휴사별 한 번만 |
| 구독 확인(선택) | 구독 목록을 공개한 사람 중 미구독자에게는 "구독 후 다시 댓글" 안내 |
| 테스트모드 | 실제로 답글을 달지 않고 시트에만 기록해서 미리 확인 |
| 대시보드 | 오늘/전체 답글 수, 보낸 메일 수, 오류 건수, 남은 메일 한도 |
| 내 영상 목록 | 내 채널 영상 전체의 조회수·좋아요·댓글·자동답글 수를 매일 정리 |
| **새 영상 자동화** | 새 영상을 올리면 자동 감지 → 캠페인 적용 + 안내 댓글 작성 + 나에게 알림 메일 |

## 꼭 알아둘 한계 (유튜브·구글 정책)

- **좋아요 여부는 확인할 수 없습니다.** 유튜브 API가 "누가 좋아요를 눌렀는지"를 공개하지 않습니다. → 답글 문구에 "좋아요·구독 부탁드려요"처럼 요청하는 방식으로 운영하세요.
- **구독 여부**는 그 사람이 구독 목록을 *공개*한 경우에만 확인됩니다 (대부분 비공개라 통과됨).
- **하루 답글 약 190개가 최대**입니다. 유튜브 API 무료 할당량(하루 10,000)에서 답글 1개가 50을 씁니다. 기본값은 하루 150개로 막아뒀습니다. 더 필요하면 구글에 할당량 증가 신청을 해야 합니다. (할당량은 한국시간 오후 4~5시에 초기화)
- **메일은 일반 Gmail 계정이 하루 100통**, Google Workspace 계정은 하루 1,500통까지입니다. 한도를 넘은 접수는 "발송실패"로 남았다가 다음 날 자동으로 다시 보냅니다.
- 같은 문구·링크가 들어간 답글을 대량으로 달면 유튜브가 스팸으로 볼 수 있습니다. **답글 버전을 2~3개 이상** 만들어두고, 레퍼럴 링크는 댓글에 넣지 마세요(이 봇은 원래 넣지 않습니다).
- 제휴 링크를 홍보하는 영상은 유튜브의 **유료 프로모션 표시**와 공정위 **"광고/제휴" 표기** 규정을 지켜주세요.
- 폼에는 **개인정보 수집·이용 동의** 문항이 자동으로 들어갑니다. 받은 이메일은 레퍼럴 발송 목적으로만 쓰세요.

## 설치 (처음 한 번, 약 15분)

> 반드시 **유튜브 채널을 소유한 구글 계정**으로 진행하세요. 메일도 이 계정 Gmail에서 나갑니다.

### 1) 구글 시트 만들고 코드 붙여넣기
1. [sheets.new](https://sheets.new) 로 새 구글 시트를 만들고 이름을 `유튜브 자동화` 등으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 **⚙️ 프로젝트 설정** → **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 를 체크합니다.
4. 왼쪽 **편집기(＜＞)** 로 돌아와서
   - `appsscript.json` 내용을 전부 지우고 이 폴더의 [`appsscript.json`](appsscript.json) 내용을 붙여넣기
   - `코드.gs`(또는 `Code.gs`) 내용을 전부 지우고 이 폴더의 [`Code.gs`](Code.gs) 내용을 붙여넣기
5. 💾 저장 (Ctrl+S)

> `appsscript.json` 이 YouTube Data API 서비스를 자동으로 켜줍니다. 혹시 "YouTube is not defined" 오류가 나면 왼쪽 **서비스 ＋ → YouTube Data API v3 → 추가** 를 눌러주세요.

### 2) 시트 준비
1. 구글 시트 탭으로 돌아와 **새로고침(F5)** → 상단에 **🤖 AI 자비스** 메뉴가 생깁니다.
2. **① 처음 설정 (시트 만들기)** 클릭
3. 권한 승인 창이 뜨면: 계정 선택 → *"Google에서 확인하지 않은 앱"* 이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**
   (내가 만든 내 스크립트라서 나오는 정상 안내입니다. 브랜드 계정 채널이면 이 단계에서 해당 채널을 고르세요.)
4. 다시 **① 처음 설정** 을 한 번 더 누르면 시트들이 만들어집니다.
5. **② 내 채널 확인** → 내 채널 이름이 맞게 나오는지 확인

### 3) 캠페인(제휴사) 입력 — `캠페인` 시트
예시로 "후커블" 줄이 들어 있습니다. 칸 제목에 마우스를 올리면 설명이 나옵니다.

| 칸 | 넣을 것 | 예시 |
|---|---|---|
| 사용 | 체크한 줄만 동작 | ☑ |
| 제휴사 | 이름 | 후커블 |
| 대상 영상 | 비우면 **전체 영상**. 특정 영상만이면 주소/ID를 쉼표로 | `https://www.youtube.com/watch?v=L1X_BF5mha4` |
| 키워드 | 쉼표로 여러 개. 띄어쓰기·대소문자·기호 무시 | `후커블, hookable` |
| 일치 방식 | **포함**(댓글 안에 있으면) / **정확히**(댓글이 키워드 그 자체) | 포함 |
| 답글 내용 | 대댓글 문구. `---` 줄로 여러 버전 | 아래 참고 |
| 레퍼럴 링크 | **비밀 링크** (메일로만 나감) | `https://hookable.../ref=xxxx` |
| 메일 제목 / 메일 내용 | 구독자에게 갈 메일 | 아래 참고 |
| 새 영상 자동 적용 | 체크하면 새 영상이 올라올 때 [대상 영상]에 자동 추가 (대상 영상이 비어 있으면 원래 전체 적용) | ☑ |
| 새 영상 안내 댓글 | 새 영상에 내 채널 이름으로 자동으로 남길 안내 댓글. 비우면 안 남김 | `📢 댓글에 "{keyword}" 남기면 혜택!` |

**답글에 쓸 수 있는 자리표시**

| 표시 | 바뀌는 내용 |
|---|---|
| `{name}` | 댓글 작성자 이름 (`@핸들` → 알림이 감) |
| `{code}` | 그 사람 전용 1회용 인증코드 |
| `{form_code}` | 인증코드가 **미리 입력된** 폼 주소 (추천) |
| `{form}` | 그냥 폼 주소 |
| `{campaign}` | 제휴사 이름 |

**메일에 쓸 수 있는 자리표시**: `{name}` `{email}` `{campaign}` `{link}`(레퍼럴 링크) `{code}` `{channel}`(내 채널 이름)
`{link}` 를 깜빡해도 메일 맨 아래에 링크가 자동으로 붙습니다.

### 4) 신청 폼 만들기
**③ 신청 구글폼 만들기** 클릭 → 폼이 자동으로 만들어지고 주소가 `설정` 시트에 들어갑니다.
폼에는 "이메일 / 인증코드 / 개인정보 동의" 3문항이 있고, 응답은 이 시트의 새 탭에 쌓입니다.
폼 디자인·문구는 `설정 → 구글폼 편집 주소` 에서 바꿀 수 있습니다. (**질문 제목의 "메일", "코드" 글자는 남겨두세요** — 봇이 이 글자로 칸을 찾습니다.)

> 구글폼이 아닌 다른 접수 페이지를 쓰고 싶다면: 그 페이지가 이 시트에 "이메일", "코드" 열로 행을 추가하도록만 연결하면 똑같이 동작합니다. (`설정 → 구글폼 주소` 에 그 주소를 넣으세요.)

### 5) 테스트 (테스트모드 = 예 상태)
1. 내 영상에 다른 계정으로 `후커블` 댓글을 하나 답니다.
2. 메뉴 **지금 댓글 · 새 영상 확인하기** → `답글기록` 시트에 **상태 "테스트"** 줄과 *달릴 예정이던 답글*이 보이면 성공. (유튜브에는 아직 안 달림)
3. 그 줄의 **인증코드**로 폼을 직접 제출해 보세요 → 내 메일함에 레퍼럴 메일이 오면 메일 흐름까지 성공!

### 6) 실제 운영 시작
1. `설정 → 테스트모드` 를 **아니오** 로 변경
2. **④ 자동 실행 켜기** 클릭 → 끝!
   - 10분마다(설정에서 1·5·10·15·30분 선택) 새 댓글 확인 → 답글
   - 폼 접수 즉시 메일 발송 (놓친 접수도 다음 확인 때 자동 처리)
   - 매일 아침 6시 `내영상` 시트 새로고침
   - 같은 주기로 **새 영상 감지** → 캠페인 자동 적용 · 안내 댓글 · 알림 메일

멈추고 싶으면 **자동 실행 끄기**.

## 🎬 새 영상 자동화 (업로드만 하면 끝)

자비스를 켠 **이후에 공개된 영상**을 확인 주기마다 감지합니다. (예약 공개 영상은 실제로 공개된 뒤 처리)

1. **캠페인 자동 적용**: `대상 영상`이 비어 있는 캠페인은 원래 모든 영상에 적용됩니다. 특정 영상만 지정해 둔 캠페인은 `새 영상 자동 적용`에 체크되어 있으면 새 영상 ID가 자동으로 추가됩니다.
2. **안내 댓글**: 적용된 캠페인들의 `새 영상 안내 댓글`을 모아 내 채널 이름으로 댓글 1개를 남깁니다. 예: *📢 이 영상 댓글에 "후커블"을 남겨주시면 후커블 전용 혜택 링크를 답글로 보내드려요!*
3. **알림 메일**: "새 영상 감지: (제목)" 메일이 나에게 옵니다. (`설정 → 알림 받을 이메일`, "끄기"로 끔)
4. 그 영상에 달리는 키워드 댓글에도 바로 자동 답글이 달립니다.

> 유튜브 API로는 댓글 **고정(핀)** 을 할 수 없습니다. 알림 메일을 받으면 유튜브 스튜디오에서 안내 댓글을 직접 고정해 주세요.
> 기능을 끄려면 `설정 → 새 영상 자동화` 를 "아니오"로.

## 시트 설명

| 시트 | 내용 |
|---|---|
| 대시보드 | 오늘/전체 답글·메일 수, 오류 건수, 남은 메일 한도, 마지막 실행 결과 |
| 설정 | 테스트모드, 확인 주기, 하루 최대 답글, 폼 주소, 보내는 사람 이름, 구독 확인 등 |
| 캠페인 | 제휴사별 키워드·답글·레퍼럴 링크·메일 문구 |
| 답글기록 | 봇이 반응한 모든 댓글과 보낸 답글, 인증코드, 코드 사용 여부 |
| 메일기록 | 모든 폼 접수와 처리 결과 (발송완료 / 코드 없음 / 이미 사용된 코드 / 중복 이메일 / 발송실패 …) |
| 내영상 | 내 채널 영상 목록과 통계, 영상별 자동 답글 수 |
| 새영상기록 | 자비스가 감지한 새 영상과 적용된 제휴사, 남긴 안내 댓글 |
| 설문지 응답 시트1 | 구글폼 원본 응답 (자동 생성) |

### 상태 뜻
- **답글완료**: 유튜브에 실제로 대댓글을 달았음
- **테스트**: 테스트모드라 기록만 함
- **중복(답글 안 함)**: 같은 사람이 같은 제휴사 키워드를 또 달아서 건너뜀
- **미구독 답글**: 구독 확인 켰을 때, 미구독자에게 안내 답글
- **실패**: 유튜브 오류. 3번까지 자동 재시도
- **발송실패**: 메일 한도 초과 등. 다음 확인 때 자동 재발송 (또는 메뉴 *밀린 접수 · 실패 메일 다시 처리*)

## 자주 묻는 질문

**Q. 답글이 안 달려요.**
`대시보드 → 마지막 실행 결과` 를 보세요. "사용 중인 캠페인이 없음"이면 캠페인 줄의 체크박스·키워드·답글 내용을 확인하고, 테스트모드가 "예"인지도 확인하세요. 유튜브가 검토 대기로 보류한 댓글은 승인되기 전까지 보이지 않습니다.

**Q. 키워드는 바꿨는데 이미 지나간 댓글에도 달고 싶어요.**
기본은 마지막 확인 6시간 전까지만 다시 봅니다. 더 예전 댓글까지 보려면 Apps Script 편집기 → ⚙️ 프로젝트 설정 → 스크립트 속성에서 `WATERMARK` 를 지우세요. 그러면 `처음 확인할 과거 시간`(기본 7일) 만큼 다시 훑습니다. (이미 답글 단 댓글엔 다시 달지 않습니다.)

**Q. 인증코드가 공개 답글에 보이는데 남이 가로채면요?**
코드는 1회용이라 먼저 쓴 한 명만 받을 수 있고, 모든 시도는 `메일기록` 에 남습니다. 레퍼럴 링크 자체는 댓글에 절대 나가지 않습니다.

**Q. 권한 승인 화면이 무서워요.**
이 스크립트는 내 시트 안에서만 돌고, 사용하는 권한은 *시트 편집 · 폼 생성 · 내 유튜브 댓글 작성 · 내 Gmail로 메일 보내기 · 자동 실행 예약* 뿐입니다 ([`appsscript.json`](appsscript.json) 의 `oauthScopes` 참고).

## 개발자용

- 구조: `Code.gs` 한 파일. 시트가 곧 설정/DB이고, 시간 트리거(`checkComments`, `refreshVideos`) + 스프레드시트 폼 제출 트리거(`onFormSubmitHandler`) 로 동작합니다.

- 로컬 테스트 (구글 서비스 가짜 구현 위에서 전체 흐름 검증):
  ```bash
  node youtube-referral-bot/test/run-tests.js
  ```
