# 두고푸드 상품 DB 플랫폼 브리프

## Actors and loops
- **상품 열람자:** `/` 진입 → 흰색 배경의 한국시간·선택 가능한 6개 지역날씨·선과장 운영상태·월간 신규/품절 현황 확인 → 등록 상품·옵션 요약 다음에 바로 이어지는 단가표에서 배송유형·카테고리·월별 판매기간·검색으로 상품 탐색 → 큰 썸네일과 상품별 옵션을 한 행씩 펼쳐 A단가/일반공급가·자율/지정 판매가 확인 → `공지사항`에서 운영 공지·필독·FAQ를 확인하고 `가격변동`에서 최근 3일 변동만 확인.
- **마스터 관리자:** `/admin`에서 `admin` 계정으로 로그인 → 중앙 대형 상품 편집 팝업과 게시판형 소싱 요청 관리 화면에서 상품과 옵션/카테고리/공지/필독사항·FAQ/요청 상태 관리 → 저장 → 공개 화면에 반영 → 상품 또는 옵션 가격 변경 시 동일한 수정시각으로 생성된 변경 이력 확인.
- **소싱 요청자:** 공개 전역 팝업 또는 `/sourcing`에서 요청 상품·희망 조건·참고 URL·연락처 입력 → 서버에 저장 → 마스터 `/admin/sourcing`에서 요청 내용과 참고 링크를 확인하고 처리 상태 변경.
- **상품 운영자:** `/admin/products`에서 일반상품만 등록·수정·품절 처리하고 → `/admin/shippingPolicies`에서 배송 정책을 등록 → 일반상품 편집기에서 정책 선택 → 공개 단가표에 같은 원본 상품 수·카테고리·가격으로 반영.
- **매입처 운영자:** `/admin/suppliers`에서 매입처명·사업자번호·대표자·연락처·주소·메모를 등록·수정·사용중지 → 상품 편집기에서 활성 매입처를 선택 → 상품 목록과 매입처별 통계의 기준으로 사용.

## Affordance inventory
- `/`: 사용자 제공 두고푸드 컬러 로고, 공식홈페이지·도매몰 외부 링크, 흰색 페이지 배경과 지역 버튼으로 전환 가능한 날씨·오전/낮/밤에 따라 색·아이콘·은은한 모션이 바뀌는 흰색 주요 날씨 카드·초록/화이트 운영 카드, 3열 운영정보, 등록 상품·옵션 요약, 검색, 국내배송/해외배송·7개 이모지 대카테고리·월별 판매기간 필터, 페이지당 상품 10개와 숫자형 페이지 이동, 원가·마진·출고배송을 제외한 셀러용 일반상품 테이블, 모바일 상품명 바로 아래 옵션 펼치기. 단가표 홈에는 공지사항 카드나 빠른 메뉴를 중복 노출하지 않는다.
- `/notices`: 최근 3일 가격변동 시세판만 표시하며 공지·필독 콘텐츠를 섞지 않는다.
- `/guide`: 공개 메뉴 이름은 `공지사항`이며 운영 공지 대형 팝업, 필독 하이라이트, 발주 정보·방법, 배송/CS 안내, 기타 안내, FAQ 아코디언을 제공한다.
- `/sourcing`: 상품 참고 URL을 포함한 소싱 요청 폼과 제출 완료 상태. 같은 입력 구조를 공개 전역 소싱 팝업에서도 제공한다.
- `/admin`: 마스터 로그인. 성공 시 운영 홈 `/admin/home`으로 이동.
- `/admin/products`: 상품 검색, 중앙 대형 팝업의 신규 등록·수정, 노출/품절 관리, 상품코드, 기본 및 옵션별 A단가·일반공급가·자율/지정 판매가·품절 관리, 판매 시작/종료월, 이미지 URL 입력, 발주오라형 상품 리스트/일괄변경 엑셀 다운로드·미리보기·적용.
- `/admin/products`: 국내/해외배송·카테고리·판매월·검색 필터, 판매기간 오른쪽 원가/A단가 마진 열, 상품별 옵션 단가 펼치기/접기를 제공한다.
- `/admin/products`: 기본 10개씩 보기와 10/20/30 표시 개수 선택, 숫자형 페이지 이동, 상품 리스트 엑셀 다운로드, 매입처·원가·A단가·일반공급가·판매가·정수 마진율을 제공한다.
- `/admin/products`: 노출순서 관리 팝업에서 검색·카테고리·10/20/30개 보기와 위/아래·맨 위 이동을 제공하고 저장된 전역 순서를 공개 전체 목록과 카테고리 필터에 동일하게 적용한다.
- `/admin/bundles`: 기존 경로는 일반상품 운영으로 안전하게 이동하며 묶음상품 등록·수정·삭제 기능은 사용하지 않는다.
- `/admin/suppliers`: 발주오라형 매입처 목록과 신규 등록·수정·사용중지 팝업을 제공하며, 상품 편집기에서 활성 매입처를 선택한다.
- `/admin/shippingPolicies`: 국내/해외 배송 정책을 등록·수정·삭제하고 일반상품 편집기에서 선택한다.
- `/admin/changes`: 신규상품·가격·품절·이미지·삭제 등 발주오라 전송 전 최종 변경내용을 검토한다.
- `/admin/transmissions`: 발주오라 읽기/쓰기 실행 결과와 성공·실패·보류 상태를 확인한다.
- `/admin/categories`: 국내배송/해외배송 그룹과 세부 카테고리 추가·수정·삭제.
- `/admin/sales`: 월간 KPI, 날짜별 매출·순이익·주문 수 달력, 매입처별 매출 집계를 제공한다. 주문 원본이 연결되지 않은 경우 샘플 수치를 만들지 않고 연결 대기 상태를 표시한다.
- `/admin/notices`: 공지, 필독 하이라이트, 발주 정보·방법, CS 기준, 기타 안내와 FAQ 추가·수정·삭제.
- `/admin/history`: 가격 변경 날짜·요일·상품·옵션·변경 항목·변경 전후 금액·관리자 기록. 인상은 빨강, 인하는 파랑으로 구분.
- `/admin/sourcing`: 상태 탭·검색·게시판 목록·중앙 상세 팝업에서 접수된 소싱 요청과 접수/검토중/완료 상태를 관리하며 완료 건도 이력으로 유지.

## Data flow
- 서버 DB가 상품, 카테고리, 공지, 필독사항, 소싱 요청, 가격변경 이력의 단일 원본이다.
- 상품은 배송유형, 카테고리, 상품명, 썸네일, 원산지, 기본 A단가, 기본 일반공급가, 자율/지정 판매가, 판매 시작/종료월, 배송비, 출하시기, 참고사항, 포장방법, 택배사, 노출/품절 상태를 가진다.
- 상품 옵션은 상품에 종속되며 옵션명, A단가, 일반공급가, 자율/지정 판매가, 품절, 정렬순서를 가진다. 등록 상품 수는 상품별 `max(1, 옵션 수)`의 판매 단위 합계로 표시한다.
- 농산·수산·축산·선물세트·식품만 월별 판매기간을 적용한다. 건강식품은 기간 필터 대상이 아니며 지정 판매가 정책을 사용한다. 실제 품절 상품은 연한 빨간색 배경과 `품절`로 표시하고, 공급중 상품은 흰색 배경으로 표시한다. 판매기간 밖 상품은 흰색 배경의 `시즌 준비중`으로 구분한다.
- 신규 상품 및 상품/옵션의 품절·재입고 전환은 활동 이력으로 기록한다. 월간 신규는 현재 노출 상품의 생성시각, 월간 품절은 해당 월의 품절 전환 이력을 한국시간 기준으로 집계한다.
- 필독사항과 FAQ는 구조화 JSON 설정으로 저장되어 공개 안내 카드와 관리자 편집기가 같은 원본을 사용한다.
- 공개 읽기 API는 노출 상품·카테고리·공지와 최근 72시간 가격변동을 반환한다. 관리자 가격 이력은 계속 보관한다. 모든 관리 쓰기 API는 마스터 권한을 요구한다.
- 운영정보 API는 Open-Meteo 대표도시 현재 날씨(10분 캐시), Nager.Date 한국 공휴일(일 단위 캐시), 월간 DB 집계를 반환한다. 일요일과 한국 공휴일은 선과장 휴무, 나머지는 정상운영으로 표시하며 공급자 오류는 확인 지연 상태로 알린다. 공개 상품과 월간 현황은 1분마다 재조회한다.
- 상품 저장 시 상품 또는 기존 옵션의 A단가/일반공급가/지정 판매가가 바뀌면 서버가 이전값과 새값을 비교하고, 상품·옵션의 `updatedAt`과 가격변경 이력 `changedAt`에 동일한 시각을 기록한다. 공개와 관리자 날짜는 한국시간으로 표시한다.
- 발주오라형 일괄변경 엑셀은 `식별ID(수정금지)` 또는 상품코드로 상품과 옵션을 매칭하며, 매입원가는 A단가, 공급가는 일반공급가로 미리보기 후 반영한다.
- 발주오라 실시간 API 연동은 데이터센터에 상품코드와 엑셀 호환 경계를 먼저 마련하고, 외부 서비스의 보안 인증/API 계약이 연결되기 전까지 관리자 화면에 연결 대기 상태를 명시한다.
- 발주오라 상품관리 전체 필터(노출·미노출/판매중·품절) 기준 2,338건을 읽기 전용 스냅샷으로 초기 이관한다. 상품코드·외부 UUID·이미지·카테고리·원가·공급가·소비자가·배송정책·택배사·노출/품절 상태는 `external_product_links`와 상품 원본 필드에 보존하고, 실행 결과는 `sync_runs`에 남긴다.
- 두고푸드 상품/가격/품절/이미지/삭제 저장은 `product_sync_outbox`에 작업과 안전모드 상태를 기록한다. 삭제는 전송 payload를 보존한 뒤 소프트 삭제한다. 공식 발주오라 쓰기 API·서버 전용 인증이 확인되기 전까지 외부 쓰기는 실행하지 않으며, 관리자 최종 변경내용·전송 내역·발주오라 연동 화면에서 보류·실패·충돌을 확인한다.
- 상품 매입처는 상품 원본에 저장되며 관리자 목록·편집기와 향후 매입처별 매출 집계의 기준으로 사용한다.
- 상품 `displayOrder`는 공개 노출의 단일 정렬 기준이며 관리자 일괄 순서 저장 API로만 변경한다. 공개 전체 목록과 카테고리 필터는 같은 정렬된 상품 배열을 사용한다.
- 이번 운영 기준에서는 묶음상품/그룹상품을 사용하지 않으며 `products.displayOrder`가 공개 일반상품 노출의 유일한 정렬 기준이다.
- 매입처는 별도 `suppliers` 원본으로 관리하고 상품에는 기존 호환 필드인 `supplierName`을 저장한다. 공급처 사용중지 시 기존 상품의 과거 매입처 텍스트는 삭제하지 않는다.
- 매출 현황은 `sales_daily_suppliers` 일별 집계를 사용하며, 발주오라 주문 원본이 없을 때 0원·연결 대기 상태를 사실대로 표시한다.

## Entitlement and boundaries
- 공개 정보 페이지와 소싱 요청 제출은 로그인 없이 이용한다.
- 공개 헤더에는 관리자 진입을 노출하지 않고, 푸터의 가격·출고 정보 변경 안내 오른쪽에 마스터 버튼을 둔다.
- `/admin/*` 화면과 관리 API는 Better Auth 세션 및 `admin` 역할을 모두 요구한다.
- 최초 마스터 계정은 아이디 `admin`으로 제공하며, 비밀번호 원문은 소스에 저장하지 않고 Better Auth 호환 해시로만 초기화한다.
- 관리자 외 사용자는 관리자 화면에 접근할 수 없고 API도 403을 반환한다.

## Acceptance checklist
- [ ] 공개·관리자 페이지에서 두고푸드 로고가 선명하게 표시된다.
- [ ] 공개·관리자 화면이 두고푸드 초록색을 주색으로 사용하고 밝은 화이트 카드, 민트 그라데이션, Pretendard 글꼴 체계를 유지한다.
- [ ] 공개 헤더에서 단가표·공지사항·가격변동·소싱·1:1 상담을 전환하고 공식홈페이지와 별도 색상의 도매몰 링크를 PC·모바일에서 사용할 수 있다.
- [ ] 공개 상품 목록에서 큰 썸네일, A단가, 일반공급가, 국내/해외배송 및 세부 카테고리를 확인하고 검색/필터할 수 있다. 일반상품은 기본 흰색, 품절 상품은 연한 빨간색 배경이다.
- [ ] `옵션 N개 보기`를 누르면 해당 상품 바로 아래에 상품 썸네일과 전체 상품명·옵션명·A단가·일반공급가·품절 상태가 한 줄씩 펼쳐진다.
- [ ] 공지사항과 최근 가격변동을 `YYYY.MM.DD (요일)` 날짜·상품·옵션·변경내용과 함께 확인하고, 인상은 빨강·인하는 파랑으로 구분한다.
- [ ] 소싱 요청자가 폼을 제출하고 마스터가 요청을 확인·처리할 수 있다.
- [ ] 마스터가 상품과 옵션을 간단히 등록·수정·비노출·품절 처리할 수 있다.

- [ ] 공개 홈 기업 모토는 `좋은 먹거리 신선함 그대로`와 생산자·판매자 연결 및 대한민국 도매 플랫폼 두고푸드 소개 문구를 표시한다.
- [ ] 공개 가격변동은 PC·모바일 모두 한 카드가 한 줄을 차지하는 가로형 레이아웃으로 표시하며, 상품·옵션·변경 전후 금액·증감액을 읽기 쉬운 크기로 제공한다.
- [ ] 공개 가격변동은 기본 5개, 10개, 20개 페이지 크기를 선택하고 하단 숫자 페이지 버튼으로 이동할 수 있으며 인상·인하 필터와 함께 동작한다.
- [ ] 상품 등록·수정에서 활성 배송 정책을 선택하면 정책명·배송비 안내·택배사가 자동으로 상품 데이터에 반영되고, 직접 입력을 선택하면 수동값을 유지한다.
- [ ] 관리자 사이드바에는 불필요한 `상품 데이터 관리` 캡션이 노출되지 않으며 `상품 관리`와 `상품 전송 현황` 그룹을 각각 접고 펼칠 수 있다.
- [ ] 통계의 매입처별 매출은 매출액 내림차순 1·2·3순위, 순수익, 판매 건수를 함께 표시한다.
- [ ] 변경 큐는 `최종 변경내용 (상품 변경전)`과 `전송 내역 (상품 변경완료)`로 구분하고, 안전한 전송 계약이 열릴 때 수정 전송 성공 후 완료 탭으로 이동한다.
- [ ] 가격변동 이력은 상품 이미지를 표시하며 일반상품을 눌러 옵션별 변경 내용을 접고 펼칠 수 있다.
- [ ] 관리자 사이드바의 1차 메뉴는 `상품 전송 현황`, 2차 메뉴는 `상품 변경전`·`상품 변경완료`로 표시하고, 별도 연동 영역의 그룹 라벨은 `OPEN API`로 표시한다.
- [ ] 공개 가격변동 하단에는 관리자 품절 처리 시각 기준 최근 7일 이내 품절 이슈가 상품·옵션·처리일·상태와 함께 표시되며, 7일이 지난 항목은 서버 응답에서 자동 제외된다.
- [ ] 관리자 좌측 메뉴는 ReviewHub형 흰색 고정 사이드바·초록색 주요 액션·활성 메뉴·접이식 하위 메뉴 계층을 두고 PC·모바일에서 동일하게 사용할 수 있다.
